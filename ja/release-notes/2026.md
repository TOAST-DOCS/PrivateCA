## 2026. 09. 15.

### 新機能の追加

- 証明書/発行者リストへのステータスフィルター（有効/期限切れ/失効）追加

<a id="march-24-2026"></a>
## 2026. 03. 24. { #march-24-2026 }

<a id="added-features"></a>
### 機能追加 { #added-features }

- API v2.0 ガイドにリポジトリAPI(一覧照会、詳細照会、作成、修正、削除)を追加しました。
- API v2.0 ガイドに証明書(発行者)API(一覧照会、詳細照会、発行、失効)を追加しました。
- API v2.0 ガイドにテンプレートAPI(一覧照会、詳細照会、作成、修正、削除、証明書発行)を追加しました。
- リポジトリ、証明書、テンプレートの一覧照会APIに、ページネーション及び検索クエリパラメータを追加しました。

<a id="feature-updates"></a>
### 機能改善・変更 { #feature-updates }

- API v2.0のエンドポイントパスを `/cas/{caId}` から `/ca-stores/{caStoreId}` に変更しました。
- API v2.0 ガイドのリクエストフィールドに制約条件(最大長、値の範囲、デフォルト値など)を詳細に記載しました。

## 2026. 01. 27. { #january-27-2026 }

<a id="january-27-2026-feature-updates"></a>
### 機能改善・変更 { #january-27-2026-feature-updates }

- バックデートの有効期間の最大値を30日に制限しました。

- **ACME 詳細**タブで、特定の状況での画面遷移時にエラーモーダルが発生するバグを修正しました。
