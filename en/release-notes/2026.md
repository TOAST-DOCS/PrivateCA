## October 13, 2026 { #october-13-2026 }

<a id="october-13-2026-feature-updates"></a>
### Feature Updates { #october-13-2026-feature-updates }
- Unified the input validation criteria between the API and the console. Incorrectly formatted DNS/IP/URI SANs, invalid OIDs, hostnames containing an underscore (_) (for example, my_host), and DNS SANs in IP address format are now rejected with an `INVALID_PARAMETER` error on API requests.
- If a previously saved template contains an invalid OID, validation may fail when you modify the template. Correct the value and save it again.
- Improved the console so that when input validation fails, the section that contains the field with the error automatically expands and the view scrolls to the first error section.

<a id="september-15-2026"></a>
## September 15, 2026 { #september-15-2026 }

<a id="september-15-2026-added-features"></a>
### Added Features { #september-15-2026-added-features }

- Added status filters (Active/Expired/Revoked) to the certificate/issuer list
- Added the feature to delete expired or revoked certificates/issuers from the list
- Added CloudTrail event logging and certificate history recording when deleting a certificate

<a id="march-24-2026"></a>
## March 24, 2026 { #march-24-2026 }

<a id="added-features"></a>
### Added Features { #added-features }

- Added repository APIs (list, get, create, update, and delete) to the API v2.0 guide.
- Added certificate (issuer) APIs (list, get, issue, and revoke) to the API v2.0 guide.
- Added template APIs (list, get, create, update, delete, and issue certificate) to the API v2.0 guide.
- Added pagination and search query parameters to the repository, certificate, and template list APIs.

<a id="feature-updates"></a>
### Feature Updates { #feature-updates }

- Updated the API v2.0 endpoint path from `/cas/{caId}` to `/ca-stores/{caStoreId}`.
- Added detailed constraints (maximum length, value range, default values, etc.) to the request fields in the API v2.0 guide.

<a id="january-27-2026"></a>
## January 27, 2026 { #january-27-2026 }

<a id="january-27-2026-feature-updates"></a>
### Feature Updates { #january-27-2026-feature-updates }

- Limited the maximum backdate period to 30 days.
- Updated the label "Expiration Settings" to "Certificate Lifetime" within **Templates > Expiration Settings**.
- Improved the clarity of error messages triggered by unauthorized user actions.

<a id="bug-fixes"></a>
### Bug Fixes { #bug-fixes }

- Fixed an issue where the expiration method was incorrectly displayed as "TTL" when set to a "Specific Date" in templates.
- Fixed an issue where an error modal appeared during screen transitions in the **ACME Details** tab under certain conditions.
