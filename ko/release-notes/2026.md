## 2026. 10. 13. { #october-13-2026 }

<a id="october-13-2026-feature-updates"></a>
### 기능 개선/변경 { #october-13-2026-feature-updates }
- API와 콘솔의 입력 값 검증 기준을 통일했습니다. 형식이 올바르지 않은 DNS/IP/URI SAN, 잘못된 OID, 언더스코어(_)가 포함된 호스트명(예: my_host), IP 주소 형태의 DNS SAN은 API 요청 시 `INVALID_PARAMETER` 오류로 거부됩니다.
- 기존에 저장된 템플릿에 잘못된 OID가 포함된 경우 템플릿 수정 시 검증에 실패할 수 있습니다. 해당 값을 올바르게 수정한 후 저장하세요.
- 콘솔에서 입력 값 검증에 실패하면 오류가 발생한 필드가 속한 섹션이 자동으로 펼쳐지고, 첫 번째 오류 섹션으로 스크롤되도록 개선했습니다.

<a id="september-15-2026"></a>
## 2026. 09. 15. { #september-15-2026 }

<a id="september-15-2026-added-features"></a>
### 기능 추가 { #september-15-2026-added-features }
- 인증서/발급자 목록에 상태 필터(활성/만료/폐기)를 추가했습니다.
- 만료 또는 폐기된 인증서/발급자를 목록에서 삭제하는 기능을 추가했습니다.
- 인증서 삭제 시 CloudTrail 이벤트 및 인증서 이력을 기록하도록 추가했습니다.

<a id="march-24-2026"></a>
## 2026. 03. 24. { #march-24-2026 }

<a id="added-features"></a>
### 기능 추가 { #added-features }
- API v2.0 가이드에 저장소 API(목록 조회, 상세 조회, 생성, 수정, 삭제)를 추가했습니다.
- API v2.0 가이드에 인증서(발급자) API(목록 조회, 상세 조회, 발급, 폐기)를 추가했습니다.
- API v2.0 가이드에 템플릿 API(목록 조회, 상세 조회, 생성, 수정, 삭제, 인증서 발급)를 추가했습니다.
- 저장소, 인증서, 템플릿 목록 조회 API에 페이지네이션 및 검색 Query Parameters를 추가했습니다.

<a id="feature-updates"></a>
### 기능 개선/변경 { #feature-updates }
- API v2.0의 엔드포인트 경로를 `/cas/{caId}`에서 `/ca-stores/{caStoreId}`로 변경했습니다.
- API v2.0 가이드의 요청 필드에 제약 조건(최대 길이, 값 범위, 기본값 등)을 상세히 기재했습니다.

<a id="january-27-2026"></a>
## 2026. 01. 27. { #january-27-2026 }

<a id="january-27-2026-feature-updates"></a>
### 기능 개선/변경 { #january-27-2026-feature-updates }
- 백데이트 유효성의 최댓값을 30일로 제한했습니다.
- **템플릿 > 만료 설정** 내 만료 설정 값의 문구를 인증서 수명으로 수정했습니다.
- 권한이 없는 사용자의 동작 시 오류 메시지를 명확하게 수정했습니다.

<a id="bug-fixes"></a>
### 버그 수정 { #bug-fixes }
- 템플릿 내 만료 방식을 특정 날짜로 수정 시 TTL로 노출되는 버그를 수정했습니다.
- **ACME 상세보기** 탭에서 특정 상황의 화면 전환 간 오류 모달이 발생하는 버그를 수정했습니다.
